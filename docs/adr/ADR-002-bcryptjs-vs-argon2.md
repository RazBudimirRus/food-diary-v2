# ADR-002 — bcryptjs вместо argon2

**Дата:** 2026-06-25  
**Статус:** Принято  
**Автор:** Глеб Сердитых

## Контекст

Выбор алгоритма хеширования паролей для Node.js приложения.

## Решение

Использовать `bcryptjs` (pure JS реализация bcrypt) с cost factor 12.

## Последствия

**Плюсы:**

- Нет нативных зависимостей — работает без `node-gyp` в Docker без дополнительных build tools
- Широко известен, хорошо протестирован
- Cost factor 12 даёт ~300ms на хеш — достаточно для защиты от брутфорса

**Минусы:**

- argon2id признан NIST предпочтительным (PHC winner, memory-hard)
- bcryptjs медленнее нативного bcrypt примерно в 3x
- Максимальная длина пароля 72 символа (ограничение bcrypt)

**Путь миграции:** при переходе на argon2 — нужен ре-хеш при следующем логине (стратегия lazy migration).
