# ADR-001 — SQLite вместо PostgreSQL

**Дата:** 2026-06-25  
**Статус:** Принято  
**Автор:** Глеб Сердитых

## Контекст

Проект запускается как персональный сервис дневника питания для нескольких пользователей (врач + пациенты). Нагрузка прогнозируется < 100 RPS, объём БД < 1 GB на горизонте 2–3 лет. Сервер — один VPS без репликации.

## Решение

Использовать SQLite через `better-sqlite3` + Drizzle ORM. Файл БД монтируется как Docker volume.

## Последствия

**Плюсы:**

- Нулевые операционные расходы: нет отдельного сервиса PostgreSQL
- Простой backup: `cp data.db backup/`
- Синхронный API `better-sqlite3` — проще транзакции
- Drizzle ORM поддерживает PostgreSQL без смены кода — миграция тривиальна

**Минусы:**

- Нет параллельных write-запросов (WAL mode включён, но write lock один)
- Нет горизонтального масштабирования

**Триггеры для миграции на PostgreSQL:** > 1000 пользователей ИЛИ > 10 GB БД ИЛИ > 100 RPS sustained.
